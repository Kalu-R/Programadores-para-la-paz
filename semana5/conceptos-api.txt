La ruta POST /reporte recibe información enviada por el usuario mediante una solicitud POST. En este caso recibe un mensaje y devuelve una respuesta en formato JSON confirmando que el reporte fue recibido.

Esta ruta podría servir en una aplicación comunitaria para que los ciudadanos envíen reportes sobre problemas del barrio, daños en servicios públicos, alertas de seguridad o solicitudes de apoyo, permitiendo organizar la información de manera más eficiente.
