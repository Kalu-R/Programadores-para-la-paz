El login es el proceso que permite identificar a un usuario antes de ingresar a una aplicación.
Gracias a esto, cada persona puede acceder únicamente a las funciones que le corresponden.
Además, algunas rutas deben estar protegidas porque contienen información privada o permiten realizar cambios importantes.
De esta manera, se evita que personas no autorizadas accedan a datos o funciones del sistema.
Tampoco se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de acceso ni otros datos sensibles de la comunidad.
